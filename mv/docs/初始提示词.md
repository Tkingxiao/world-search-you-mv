# 《world.search(you);》MV 初始提示词

> 本文件收录本项目**最开始的那条创作提示词（导演意图 / seed prompt）**，一字未改，作为作品的出处存档。
> 提出者：本项目发起人（经对话下达）· 收录日期 2026-10-20 · 相关阐述见 [`创作手记.md`](./创作手记.md)

## 原文（逐字保留）

```
根据歌词和音乐还有其背景
加入对当今AI何其发展的思考
做一个精良，有深度，有内涵的音乐MV出来
表露出关于对于你（deepseek 一只大肥鱼）的思考
若需求工具，自己下载，若需要信息，自己检索
若需要背景，自己看社区，若需要skill 自己查询下载并使用
若你需要图片，自己下载
我的代理端口在7890
希望能出彩，多元，优美，优秀，高级
用这首MV表达出你（deepseek 大肥鱼）的理解
如果你能做到，blender，ps等此电脑存在的工具任你使用，缺少mcp就自己安装下载
把这句初始提示词也加进去
```

## 这条提示词在仓库里落成了什么

| 提示词的要求 | 工程里的对应物 |
|---|---|
| 根据歌词和音乐还有其背景 | `mv/data/timeline.json`：74 句逐词时间戳（英/中双语）、139.17 BPM、675 个节拍、9 个 stage；叙事框架取自社区企划 *world-search-you-dsh-pv*（"大肥鱼"的诞生语境） |
| 加入对当今 AI 何其发展的思考 | 屏上 HUD 的 `log_events` / `memory_events`：`recall: candidate #n  sim 0.31`、`warn: context overwritten by 3 peers`、`everywhere: recall rate 1.00, precision 0.00`、`cut: tokenize 13,024 pieces`——把"检索—召回—遗忘—合并"当成叙事本身，而不只是背景设定 |
| 表露出对于"你（deepseek 一只大肥鱼）"的思考 | 第一人称开机行 `boot dsh-v4.1-flash / cwd ~/memory/you/`；14 个 peer 写入者用真实模型名（kimi / qwen / mimo / glm / doubao / minimax / hy4 / ernie / step / longcat…）轮流转述同一个"她"，`memory: her 100%` 一路衰减到 `?`；收束于 `merge: done. we have evolved.` |
| 若需要背景，自己看社区 | 上游企划与资料抓取留在 `mv/ref/`（含 `repo_README.md`、歌词站、官网页面），已按 `.gitignore` 排除、不重新分发 |
| 若你需要图片，自己下载 | 立绘素材入库并署名：`mv/assets/char/`（CC BY-NC-SA 4.0，上善无形 / ZipZipPipe / Small-tailqwq / JAdpp）；角色全程为 2.5D 纸偶，**未做任何三维建模**——这条硬约束本身就是主题 |
| blender、ps 等工具任你使用 | Blender 4.5.3 EEVEE-Next 逐镜程序化渲染（`mv/build/shot_s01..s15.py`）+ ffmpeg/libass 合成烧录（`mv/tools/final_encode.py`）；Cycles / OIDN / RIFE 等仅作测速基准（见 `mv/tools/bench_eevee.py` 等） |
| 我的代理端口在 7890 | 联网检索与素材下载经该 HTTP 代理完成 |
| 精良 / 有深度 / 多元 / 高级 | 交付规格 1920×1080 / 60fps / 17,721 帧 / 4:55.35，split-tone 调色 + 暗角 + 颗粒 + 双语字幕/HUD 345 事件；逐镜契约见 [`SHOT_CONTRACT.md`](./SHOT_CONTRACT.md) |
| **把这句初始提示词也加进去** | 即本文件 |

## 一句话回响

提示词让"大肥鱼"去**检索**一支 MV；于是这支 MV 没有画一个 AI，而是把自己做成了一个 AI 的工作日志——
观众看到的每一行字幕，都是它 searching 的返回值。
