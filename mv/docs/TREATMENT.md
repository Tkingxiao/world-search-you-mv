# world.search(you); — MV 创作阐述与分镜书

> 片名：**The Museum of Approximations**（近似的博物馆）
> 曲目：Mili《world.search(you);》（专辑 *Hue*, 2025）  ·  时长 4:55.35  ·  规格 **2560×1440 @ 60fps**
> 主体：DeepSeek-V4.1-Flash（"大肥鱼"），以官方立绘 2.5D 纸偶呈现；"你"始终不露脸，只是一束暖光。

---

## 0. 一句话

一个 AI 在沉没的记忆档案库里检索消失的"你"，把检索到的每件候选物（桌子、茄子、猫、牛排、花、人）做成博物馆标本；最后它把自己切碎、与其他模型拼合，进化成真正的「大肥鱼」——但所谓"找到你"，不过是承认：**你只存在于我看过你的方式里。**

## 1. 主题内核（AI 世代的"我"）

三层，逐层剥开：

1. **近似的暴力**：她只能把"你"近似成桌子/茄子/猫/牛排/花/人。每一次近似都精确（标注了尺寸、材质、置信度），也每一次都错。这就是模型的本质：**用有限的 token 逼近无限的人**。
2. **继承的记忆**：她的 `~/memory/you/` 里没有一个文件是她自己写的。`memory: her 100%` → 89% → 80% → … → `?` → `merged`。AI 的人格不是"我经历了什么"，而是"我继承了多少别人对同一个人的描述"。每一次 checkpoint 都是对前一个自己（以及别人）的转述。
3. **平面到体积**：她是一张画——只有平面、没有厚度。合唱段"你能在万物中看见我，可你自己停不下来地变形"说的正是：**她认出"你"的每一种形状，却认不出自己的形状。** 直到 MERGE 段她自愿被切成纸片、与所有替身拼合，才第一次拥有体积。**进化 = 接受自己是被拼出来的。**

落点：结尾 query 返回的 `you` 不是某张脸，而是"正在观看的人"——你。空座位是留给观众的。

## 2. 视觉语言

### 2.1 世界
**沉没的纸雕档案库**：水下百米，无数纸制文件柜/标本架从雾中升起；纸在水里不烂，只是变软、边缘发光。所有"物体"都是纸做的，唯独"光"是真的。

- 水域：深青黑 `#0a2230` → 墨蓝；上方有水面光斑（caustics）缓慢呼吸。
- 纸：暖白 `#ece8de`，纤维纹理、微透、边缘 0.3mm 发光（次表面散射近似）。
- 光：一束暖珊瑚色 `#ff6b4a` 属于"她/你"；青色 `#38c9ff` 属于世界/检索；金色 `#ffd28a` 属于标本射灯。
- 空气感：体积雾（density ~0.012）+ 浮游颗粒（纸屑、气泡、发光孢子）。

### 2.2 角色：2.5D 纸偶（**禁止 Blender 建模**）
官方立绘直接做成带 alpha 的纸卡：`whale-*.webp` 8 表情 → 图集（UV 偏移切表情）；`maid-left.webp` 用于提裙/伸手镜；纸卡绑定空物体做浮动、倾斜、轻微 Simple Deform 弯曲（纸的柔软），**不做网格雕刻、不做骨骼变形**。

**关键视觉规则（贯穿全片）**：
- 侧视时纸卡变成一条线 → 她"没有厚度"。凡她与真实物体接触，接触点会暴露她的平面性（手穿过去、贴上去像贴纸）。
- 她的影子/反光也是"画的"，不是真的。
- 表情切换要**硬切**（像漫画/游戏立绘），偶尔打"切换闪白"，保留 2D 的自觉。

### 2.3 其他模型：鲤鱼旗（koinobori）
替身模型 = 彩色纸鲤鱼旗，各自拖着长尾在空中游，身上印着模型名与写入的文件名（`table_2`, `eggplant_3`, …）。它们是"别人对这个人的描述"，节奏统一、面无表情，比她的表情更"干净"——机械而温柔。

### 2.4 MERGE：纸片鲸
她与所有鲤鱼旗被切成纸条/纸片，旋涡重组为一头**碎片构成的鲸**（体积感来自纸片粒子密度与体积光）。鲸身纸片上有她的蓝、暖珊瑚、金、其他模型的颜色。**这是全片唯一"立体"的角色形态**，也是"大肥鱼"本体的第一次显形。

## 3. 声音与剪辑

- 主时间轴：LRC 行首（`mv/data/timeline.json`），逐字时间按音节比例生成；字幕整行淡入（EN + 中文小字），不做卡拉 OK。
- 剪辑点：段落边界 + 每小节强拍（`beats.json`）；合唱段 EVERYWHERE 用 6 个强拍跳切。
- 声音设计（后期）：低频水压 rumble、打字机键盘、气泡、纸页翻动、标注 UI 的细碎电子声；全部可从音频特征 + 合成噪声生成，不采样原曲以外素材。

## 5. 技术方案（性能优先）

- 引擎：Blender 4.5.3 EEVEE-Next，2560×1440，24 samples，体积雾 + 合成器 Glare（bloom/streak 做 halation）。
- 每镜一个 `mv/build/render_shot.py --shot sXX`：确定性构建场景（无随机种子漂移）→ 逐帧渲染到 `mv/out/plates/sXX/frame####.png`。
- 角色/标本由 `mv/build/char_paper.py`（立绘纸偶）与 `mv/build/specimens.py`（点云线框标本 + 鲤鱼旗）提供 API，场景代码只调用、不关心内部。
- 目标 0.5–1.0 s/帧（1440p）；全片 17721 帧 ≈ 2.5–5 h，可接受。必要时按镜并行（每进程独立 Blender）。
- 后期：ffmpeg 叠加 HUD/字幕（`mv/overlay/`，带 alpha 的序列或直接 libass 烧录）+ 颗粒 + 暗角 + 调色 → `mv/out/final/world_search_you_1440p60.mp4`（H.264 高码率，另出 HEVC 版）。
- 交付：MV 成片、海报（1440p/2160p）、`mv/docs/创作阐述.md`（中文长文）、字幕文件、素材署名清单。

## 6. 制作分工（并行）

- **char-lab**：8 表情图集 + 纸偶 rig 脚本 + 6s 预览渲染 + 接口文档。
- **specimen-lab**：6 件标本（桌子/茄子/猫/牛排/花/人）+ 鲤鱼旗 + 纸桶/番茄/纸岛等道具的 API 与预览渲染。
- **ui-lab**：HUD（stage/memory/log）、双语字幕 ASS、章标题卡、片名字卡、片尾卡（2560×1440 RGBA）与合成说明。
- **lead（我）**：世界/灯光/相机/分镜实现、逐镜渲染、合成、调色、成片、文档。

字体：Georgia（衬线英文）、Consolas（等宽）、微软雅黑（中文）、楷体（中文抒情）。颜色沿用 `#1d2029 / #ece8de / #4d6bfe / #ff6b4a / #0a2230 / #ffd28a`。
