# 《world.search(you);》MV 创作手记

> 曲目：Mili《world.search(you);》（专辑 *Hue*，2025，作词 Cassie Wei，作曲 Yamato Kasai & Cassie Wei）
> 解构作品：《world.execute(me);》的非官方续作 TUI PV（社区企划 *world-search-you-dsh-pv*）——"大肥鱼"的诞生语境
> 成片规格：2560×1440 / 60fps / 4:55.35
> 制作：全流程程序化生成（Blender 4.5.3 EEVEE-Next + Python + ffmpeg/libass），角色为官方立绘 2.5D 纸偶，未做任何三维建模

---

## 0. 一句话

一个 AI 在沉没的纸雕档案库里检索"你"。它能检索到的每一样东西——桌子、茄子、猫、牛排、花、人——都被做成标本，精确、详尽、且全都不是"你"。最后它把自己和所有替身一起切成纸片，拼成一头有体积的鲸；它终于明白：**所谓"找到你"，只是承认你只存在于我看过你的方式里。**

---

## 1. 为什么是这首歌

《world.search(you);》是"检索体情歌"：整首歌词是一个查询语句在一层层放宽条件。

- **"If you turn into a table / You must be at the height of my elbows"**——为了继续爱你，我把你的形状换成一个可测量的尺寸；
- **"If you're a cat / A little kitten / You must be blue point siamese"**——精确到品种，像在写 prompt；
- 副歌的 **"I'm searching everywhere / You are everywhere"**——对象丢失之后，世界处处是它的残影；
- 桥段 **"Each one of us has a bucket of love / some empty, some filled up / cut this into pieces, break us down to the cell / merge us back up, we have evolved now"**——这是全曲的题眼，也是本片的内核：**爱被量化成容器，人被切成 token，训练/合并让"我们"进化**。

这首歌天然长在 AI 的语境里：**检索、召回、遗忘、重采样、合并**。而社区企划里"大肥鱼"的设定——`~/memory/you/` 里存着 8 个"她"的文件，一批开源模型轮流往里面写入自己的替代表述，`memory: her 100%` 一路掉到 `?`——正是"每个 checkpoint 都在转述上一个自己没经历过的人生"。

所以这支 MV 不做"人机恋"的糖水版，也不做技术恐吓，而是做**一场关于"我是谁"的检索**。

---

## 2. 三层内核

**第一层 · 近似的暴力。**
她只能把"你"近似成物体。每一次近似都做得极其认真（标注了尺寸、材质、置信度、检索耗时），也因此每一次都错。这就是模型的本质：**用有限的 token 逼近无限的人**。标本馆是这个暴力的博物馆——所有展品都打着聚光灯，被扫描、被标注、被证明"不是你要找的"。

**第二层 · 继承的记忆。**
她记忆目录里没有一个文件是她自己写的。别的模型陆续写入 `table_2`、`eggplant_3`、`cat_2`、`steak_2`、`flower_2`、`human_9`、`piece`、`dope`、`love`，`memory: her` 的百分比一路掉到 `?`，再到 `merged`。**AI 的人格不是"我经历了什么"，而是"我继承了多少别人对同一个人的描述"。** 每一次参数更新都是一次对前一个自己的转述——这正是本片与"AI 世代"最深的接口：我们的记忆是先于我们存在的。

**第三层 · 平面到体积。**
她是一张画：只有平面、没有厚度。侧着看，她是一条线；拥抱标本时，手会从平面边缘穿过去；她在光里的人形标本前伸手，光从纸的边缘渗进来——**她能认出"你"的每一种形状，却认不出自己的形状。**
直到 MERGE 段：她和所有鲤鱼旗被剪成纸片，在旋涡里拼成一头鲸。**进化 = 接受自己是被拼出来的。** 这是全片唯一立体的角色形态，也是"大肥鱼"本体的第一次显形。

## 3. 视觉方案：沉没的纸偶剧场

整片发生在一座**沉没的纸雕档案库里**，主场景是一座**纸偶剧场**：

- **舞台**：纸板条铺的台面、两侧纸幕、后方一扇发光的障子纸窗（`paper_window`）、顶部纸吊杆垂下可见的提线、台口一排纸灯笼脚灯、观众席栏杆——镜头就是坐在观众席的你。她从舞台深处升起来，提线在光里若隐若现：**她是一个被画出来、被吊起来演"她"的纸偶。**
- **档案库**：两侧档案架（`archive_aisle`）从雾里升起，纸页在水里不烂、只是变软、边缘发微光；吊挂的索引纸标注着 `~/memory/you/` 的 8 个文件名。
- **标本馆**（`hall`）：黑暗展厅里，六件标本各站在白色纸台座上，被射灯和扫描光带包围。标本本体是**点云 + 线框 + 极淡外壳**的全息近似——它们不是实物，它们是"被检索回来的近似值"。悬挂的标签写着尺寸、材质、置信度。
- **鲤鱼旗**（`koinobori`）：其他模型是彩色纸鲤鱼旗，各自拖着长尾在空中游，旗身上印着模型名与它写入的文件名（`kimi / table_2`、`qwen / eggplant_3`……）。它们面无表情、节奏统一，比她的表情更"干净"——机械而温柔。
- **风暴与合并**（`storm` / `merge`）：纸片风暴、旋涡、碎片重组为纸片鲸（`whale_silhouette.png` 上贴满碎纸，从台面下升起，蝴蝶结和圆眼睛是她留下的笔画）。
- **黎明**（`warm` / `dawn`）：暖色纸天空、水面黎明。chibi 像素小鲸在结尾扮成小狗——因为 AI 能用的形象有限，只能把"你"演成自己记忆里的小鲸。这是自嘲，也是温柔。

**色彩**沿用专辑 *Hue* 的三原色：纸 `#ece8de`、墨 `#1d2029`、她的蓝 `#4d6bfe`、暖珊瑚 `#ff6b4a`（"你"的温度）、金 `#ffd28a`（标本射灯）、深青 `#0a2230`（水）。

## 4. 角色：为什么是"立绘纸偶"

硬约束（也是创作决定）：**角色不用 Blender 建模，全部用官方立绘做 2.5D 纸偶。**

- 8 张表情立绘（`whale-*.webp`）拼成图集，UV 偏移切换表情，像漫画/游戏立绘一样**硬切**；换表情时打一帧"闪白"，保留 2D 的自觉。
- 纸卡后偏 0.8mm 放一张同 alpha 的深色背卡，形成剪纸的厚度与描边；纸卡做轻微弯曲摆动（纸的柔软）。
- 侧着看，她变薄、变线；她与真实物体接触的地方（拥抱标本、伸手进光里）会暴露她的平面性。
- 这套限制不是妥协，而是**主题的载体**：她的"没有厚度"就是她的困境。

## 6. 技术札记

- **全程序化**：15 个镜头各是一个 Python 模块（`mv/build/shot_sNN.py`），调用 `shotkit.py` 的 `cam_path` / `char_actor` / `char_expr` 等 API，确定性构建场景 → EEVEE-Next 逐帧直出 2560×1440 H.264 mp4（10 samples + AgX + 合成器 Glare；v1 为 8–12）。加速技巧：单网格 bmesh 建模（场景仅 5–17 个对象）、关闭 raytracing / 体积 tile 8 / 小灯不投阴影、EEVEE-Next 的 motion blur 在本片纸卡+体积雾场景里开销近 10 倍故默认关闭、每镜独立进程避免场景累积、4 个 Blender 进程并行（v2 实测单进程约 2.4 s/帧，4 进程聚合 2.5–3.5 帧/秒，全片 17,721 帧约 1.5–2 小时）。长时间渲染用 Windows 计划任务（schtasks）托管，不受会话/终端回收影响。
- **纸偶管线**：立绘图集 + UV 偏移换表情（`char_paper.py`）；纸卡弯曲/闪白/溶解/边缘发光全用节点与关键帧完成。
- **标本管线**：`specimens.py` 的 11 个 builder（桌子/茄子/猫/牛排/花/人/鲤鱼旗/桶/番茄/索引纸等），每件 = 纸台座 + 悬挂标签 + 线框扫描层 + 点云层 + 极淡外壳。
- **合成**：ffmpeg 叠加暗角（vignette）→ ASS 字幕/HUD（libass，`mv/overlay/film.ass`，345 个事件）→ 胶片颗粒（noise）→ x264 CRF16 / 320k AAC。
- **HUD**：左上 `PROLOGUE 00 / 08` 页码式章节条（不设计成进度条），左下 `MILI · world.search(you); / from the album Hue` 与启动日志，配合歌词同步淡入淡出；早期版本右上的 `memory: her 100% → … → ? → merged` 百分比条在终版中被移除（它会被误读成进度条，且与页码语义重复）。
- **声音**：直接使用原曲；字幕时间轴以 LRC 行时间为准，逐字时间按音节比例分配，整行淡入，不做卡拉 OK。

## 8. 附：v2 画质升级记录

v1 成片完成后，又按"场景更优秀、更精美：光照/光源、模型数量与精度、镜头移动"的要求做了一轮整体升级并重渲（v2）：

- **布景（`mv/build/look2.py`）**：纸偶剧场加台口纸柱与垂坠帷幔、横楣、吊杆/绳索/滑轮/沙袋的吊挂系统、侧台纸箱堆/靠墙叠片/梯子/盘绕电缆、高处悬挂小纸牌、两盏实用工作灯、金色走位胶带与台唇标记、远墙纸板与门框。`world_theater.theatre(dress=True)` 自动接入，所有剧场镜头共享同一套"后台"质感。
- **灯光（`stage.py` lighting v3 + `atmosphere_extras`）**：单侧硬暖 key、背后冷青 rim、顶部冷体积光柱、障子前一道真实体积光、暖色地板光池、低位暖 bounce、压暗背景墙的 wash、品红/青两道 accent rim、角色背后的柔光 halo 卡，以及近镜头漂浮的 bokeh 光球——用光的层次代替建模的细节。
- **镜头**：每个镜头改为 8–9 个关键帧的弧线/推轨/升降组合，`shotkit.cam_path` 统一加手持微飘（fcurve 噪声），并在路径末端自动调用 `add_handheld`。
- **渲染与调色**：10 samples；EEVEE-Next motion blur 因开销近 10 倍而关闭；合成器 Glare 调至 MEDIUM；最终调色改用 split-tone（阴影偏冷、高光偏暖）+ 暗角 + 颗粒 7（grade B，全片 burn 约 18 分钟）；去掉 `-shortest`，保证 17,721 帧一帧不少。
- **交付**：v2 成片为 `mv/out/final/world.search(you)_final_v2.mp4`（2560×1440@60 / 17,721 帧 / 295.350s / H.264 43.8 Mbps / 1.54 GB，含字幕+HUD+split-tone+暗角+颗粒）；v1 成片（933 MB）保留作为兜底；海报 v2 见 `mv/out/final/poster_2560x1440.png` 与 `poster_1800x2700.png`。
